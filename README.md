# van-nav-diao

This repository is a fork of [thirsty5034/van-nav](https://github.com/thirsty5034/van-nav).

The upstream fork is based on the original [Mereithhh/van-nav](https://github.com/Mereithhh/van-nav).

## What is different

This fork is customized for [diao.page](https://diao.page/). It adds category and tag SEO URLs, clickable tool tags, generated sitemap and `llms.txt`, Chrome bookmark import/export, compact card styling, affiliate labels, basic PageSpeed/cache improvements, and local data/schema migrations for this customized navigation site.
